This is ordinary release, not the previous PGO G1/G2 configuration or a current-head 90% acceptance run.

Four B tail values violated the pre-registered `<3%` same-source regression gate: FIFO `futex_wait_mismatch` p99 +7.674%, FIFO `process_futex_cross_cpu` p99.9 +5.882%, FIFO `thread_futex_cross_cpu` p99.9 +4.862%, and OTHER `absolute_timer_same_cpu` p99.9 +14.704%. The largest B p50 regression was +0.573% (OTHER timer); the target p50 gain was zero. These rows are not proof that the arithmetic operation itself caused the tail movement, because code layout and run-to-run variation remain possible, but the candidate fails the agreed acceptance rule and offers no target-row benefit in this source-matched trial. Do not spend further PGO training on it.

The candidate patch is archived under resume870 (SHA256 `5f796013c5d75bbc7354dced7f4142235591f9b45ffcd5722aeef367973d9f9a`) and was reverted with `apply_patch`; the main worktree is clean at `b292a098bb`.
