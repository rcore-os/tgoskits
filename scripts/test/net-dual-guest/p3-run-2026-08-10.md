# P3 run record (2026-08-10)

This is a bounded single-Guest fault-injection run over the same independent
host responder used for P1. It proves the data-link failure, heartbeat timeout,
safe state, link recovery, and real heartbeat payload handling. It is not the
30-minute stability run or the P2 dual-Guest isolation proof.
