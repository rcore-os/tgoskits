## Evidence gap

`p1.pcap` contained DHCP UDP packets but no task-2 UDP datagram. Therefore the
following verifier invocation correctly failed and P1 data-plane acceptance
remains open:

```bash
python3 scripts/test/net-dual-guest/verify_pcap.py \
  tmp/net-dual-guest/p1.pcap tmp/net-dual-guest/p1.pcap \
  --tag '' --src 10.0.42.15 --dst 10.0.42.2 \
  --port 4242 --min-udp 1 --require-task2
```

The missing packet must be diagnosed and reproduced before this record can be
updated to a passing P1 result.
