# Browser console assets

`xterm-6.0.0/xterm.js` and `xterm-6.0.0/xterm.css` are copied unchanged from
the `@xterm/xterm` 6.0.0 npm package. The corresponding MIT license is stored
next to the assets in `xterm-6.0.0/LICENSE`.

These files are compiled into the Axvisor binary and served from same-origin
HTTP routes. The board-hosted console therefore has no CDN or runtime package
manager dependency.
